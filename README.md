# 🚀 AndroidTesting Project

Welcome to **AndroidTesting**, a clean, scalable, and highly testable Android application that showcases advanced **unit testing**, **coroutines**, **Jetpack components**, and **modern CI/CD practices** with 🧪 full test coverage and 🚀 deployment automation.

## 🧩 Tech Stack

- 🛠️ **Languages:** Kotlin, Java
- 🧱 **Architecture:** MVVM + Clean Architecture
- 🔄 **Jetpack:** ViewModel, Room
- 🧪 **Testing:** JUnit, MockK, Truth, Kluent, Turbine
- 🔁 **Coroutines & Flow:** Cold Flow, Hot Flow (StateFlow, SharedFlow)
- 📦 **CI/CD:** CircleCI + Fastlane + Firebase App Distribution
- 📁 **Data Storage:** Room DB, DAO layer testing

---

## 🧪 Testing Highlights

This project focuses heavily on **testing-first development** using a rich mix of tools and strategies:

### ✅ Unit Testing
- ✅ **ViewModel Testing**  
- ✅ **UseCase Testing**  
- ✅ **Coroutines Testing**  
- ✅ **Flow Testing** (hot & cold flows)

### 🔥 Advanced Flow Testing
- 🔁 **StateFlow**, **SharedFlow**  
- 🌊 **Cold Flow Emissions**
- ⏳ Controlled testing using `TestCoroutineDispatcher`

### 🧬 Test Doubles Used
- 🎭 **Dummy**
- 🧪 **Stub** / **Spy Stub**
- 🕵️ **Mock / Spy** (Strict & Relaxed)
- 🧱 **Fake**

### 🗃️ Database Testing
- ✅ DAO and Room tests using in-memory DB
- ✅ Coroutine + Room integration tests

### 💡 Assertion Libraries
- 💬 [Kluent](https://github.com/MarkusAmshove/Kluent)
- 🧪 [Turbine](https://github.com/cashapp/turbine) for Flow emissions
